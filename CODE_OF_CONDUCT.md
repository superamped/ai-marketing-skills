# Code of Conduct

## Our standard

We want participation in this project to be respectful, useful, and safe. Contributors and maintainers should:

- Be welcoming and constructive.
- Critique ideas and outputs rather than people.
- Respect privacy, confidentiality, and intellectual property.
- Avoid harassment, discrimination, personal attacks, and unwanted promotion.
- Represent test results, compatibility, and provenance honestly.
- Accept correction and help improve the shared work.

Unacceptable behavior includes harassment, threats, discriminatory language, publishing another person’s private information, deliberate credential exposure, spam, and other conduct that would reasonably make participation unsafe.

## Scope

This code applies in repository issues, pull requests, discussions, and other project spaces, as well as when someone publicly represents the project.

## Enforcement

Report conduct concerns privately to `support@superamped.com`. Include relevant links or context, but do not unnecessarily repeat private or harmful material.

Maintainers may edit or remove contributions, comments, or other material that violates this standard and may temporarily or permanently restrict participation. Reports will be handled as privately and fairly as practical.
