# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and releases use [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- X Source Research skill for building dated, source-backed Twitter/X evidence packets with confidence labels and downstream skill handoffs.
- Optional Xquik integration guide for bounded public X collection and safe fallback inputs.

## [1.1.0] - 2026-08-17

### Added

- Agent Skills CLI installation path.
- Supported-host and integration guidance.
- Prompt-to-output examples and direct links to all 18 skills.
- Automated validation using the official Agent Skills `skills-ref` library plus repository checks for marketplace registration, internal links, and likely credential leaks.
- Explicit MIT license metadata and intent-focused trigger descriptions for every skill.
- Contribution, security, issue, and pull-request guidance.
- Social-preview artwork.

### Changed

- Repositioned the project around the established Agent Skills category.
- Kept the established `ai-marketing-skills` repository and plugin name while adding clearer Agent Skills and AI-agent positioning.
- Clarified that the packages are skills used by AI agents, not autonomous agents.
- Updated the Keywords Everywhere MCP environment-variable syntax.
- Replaced the obsolete Growth Engineering Community link with a qualified Launch Party by Superamped invitation for B2B SaaS founders.

## [1.0.0] - 2026-03-14

### Added

- Initial public collection of 18 marketing skills across advertising, content, conversion, Reddit, research, and search.
- Claude Code marketplace configuration.
- Optional Keywords Everywhere and Playwright integrations.
